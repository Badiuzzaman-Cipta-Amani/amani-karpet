# Amani Laundry Karpet

Website landing page Amani Laundry Karpet, jasa cuci karpet antar jemput di Sukabumi.

## Requirements

- Node v20 or higher
- Pnpm v11 or higher

## 🚀 Install **packages**

```bash
pnpm i
```

## Adding Astro packages

```bash
pnpm astro ...
```

## Running development mode

```bash
pnpm dev
```

## Build production

```bash
pnpm run build
```

## Preview production

```bash
# Generate production first
pnpm run build

# Preview production in local
pnpm preview
```

To learn more about the folder structure of an Astro project, refer to [our guide on project structure](https://docs.astro.build/en/basics/project-structure/).
